How StudySpace works

  1. Enter your name on the home page.
  2. Create a room, or join with a room code.
  3. The host writes on the whiteboard. The host can allow other people to write from the People list.
  4. Use the calculator button for basic, scientific and electronics tools.
  5. Use the chat to message everyone, and the mic and camera buttons to talk.
